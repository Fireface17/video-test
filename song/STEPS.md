# Пошагово: от Suno до релиза

Названия полей в Suno меняются. Если какого-то нет — скрин формы, разберёмся по нему.

## Шаг 0. Подготовка (5 мин)

1. suno.com → войти → **Create**.
2. Переключить режим на **Custom** (не Simple).
3. Модель вверху формы: **v6**.
4. Завести заметку/таблицу журнала (`song/SESSION.md`, раздел «Дубли Suno»): номер, модель, промпт, ползунки, вердикт.

## Шаг 1. Пробный прогон на v6-mini (дёшево проверить промпт)

1. Модель → **v6-mini**. Тумблер **Instrumental → ON**.
2. **Style** — вставить:
   ```
   melancholic jumpstyle phonk, 145 BPM, E minor, sad piano hook, punchy jumpstyle kick, deep 808
   ```
3. **Advanced Options**:
   - Exclude: `guitar, rap, orchestral strings`
   - Style Influence **80**, Weirdness **45**, Variety **0**, Max Mode **off**.
   - Длина ~45 с, если есть ползунок.
4. **Create** → 2 дубля. Послушать: это вообще jumpstyle-фонк в миноре? Да → шаг 2. Нет → поменять одно слово в style и повторить.

## Шаг 2. Поиск лупа на v6 (главная охота)

1. Модель → **v6**, остальное как в шаге 1.
2. Сделать **4–6 генераций** (8–12 дублей). Можно чередовать три style:
   ```
   melancholic jumpstyle phonk, 145 BPM, E minor, sad piano hook, punchy jumpstyle kick, deep 808
   ```
   ```
   sad anime phonk, jumpstyle bounce, 145 BPM, E minor, bell lead, choir pad, heavy 808
   ```
   ```
   slowed sad jumpstyle, 145 BPM, E minor, 4-note piano motif, hard kick, deep sub, loop
   ```
3. Ещё 2–3 генерации на **v6-wild** — ради необычного мотива. Найденное там проверять строже.
4. Каждый дубль — **отбраковка по первым 8 секундам** в плеере Suno (слушать бесплатно, не скачивать):
   1. первый удар сразу, без фейда;
   2. мотив запоминается за секунду;
   3. в ячейке ≤ 6 нот;
   4. второй повтор мотива **такой же**, как первый (самая частая смерть);
   5. удары видно на волне;
   6. луп зацикливается без щелчка;
   7. темп не плывёт;
   8. мелодию слышно с динамика телефона/ноутбука.
   Одно «нет» — в корзину. Нормально, если годен 1 из 8–16.
5. Годные 1–2 дубля: **скачать MP3** → загрузить в репо в `song/refs/` (через GitHub «Add files» в ветку `claude/jolly-wright-erptoy`) → написать мне. Прогоню анализатор: темп, дрейф, атака, повтор.

## Шаг 3. Полный трек с вокалом (Cover по своему лупу)

1. На годном дубле: меню **⋯ → Cover** (или Create → загрузить свой скачанный луп как аудио).
   Только свой луп из шага 2, чужие треки не грузить.
2. Тумблер **Instrumental → OFF**. Модель **v6**.
3. **Style**:
   ```
   melancholic jumpstyle phonk, 145 BPM, E minor, airy female vocal, sad piano hook, jumpstyle kick, deep 808
   ```
4. **Lyrics** — текст из `song/PLAN.md` (или твой вариант, проверенный со мной).
5. Advanced Options: Exclude `rap, male vocals, guitar` · Style Influence **60** · Audio Influence **65** ·
   Weirdness **30** · Variety **0** · Max Mode **ON** · длина ~1:30.
6. 2–4 генерации. Проверка полного трека: мотив одинаковый в дропе 1 и дропе 3, темп не уплыл,
   брейк пустой, голос не поёт лишних куплетов.
7. Чинить одним действием за раз:
   - пианино уплыло → Audio Influence **+10**;
   - вернулся почти сам луп без структуры → Audio Influence **−10**;
   - жанр поплыл → Style Influence **+10**;
   - одна строка спета не так → **сменить одну строку** (v6), не перегенерировать;
   - сломался один кусок → правка секции текстом / **Replace Section**.
8. Финальный дубль: **скачать WAV** + стемы (вокал отдельно) — входят в то же скачивание.
   Скинуть мне MP3 в `song/refs/` для проверки перед REAPER.

## Шаг 4. REAPER: сетка и паузы

1. Перетащить WAV на трек. Выделить от первого кика до кика 5-го такта →
   *Time selection: Set project tempo from time selection (detect number of measures)* → должно быть ~145.
2. Пролистать: сетка совпадает с киками до конца? Нет → дубль под эдит не годится.
3. Включить Snap, **ripple editing OFF**.
4. Паузы (точные времена — я пересчитаю под реальный старт твоего дубля):
   - FREEZE 1: последняя 1/8 такта 2 — выделить по сетке → Delete.
   - FREEZE 2: последняя 1/4 такта 10 → Delete.
5. На каждый край реза фейд **3 мс**.
6. Если нет чистого интро: 2 такта мотива → копия на отдельный трек → ReaEQ HPF 250 Гц Q 2.0 + полка 3 кГц +3 дБ.

## Шаг 5. REAPER: jumpstyle-перегруз (параллельно)

1. Дублировать итем на трек 2.
2. Трек 2: ReaEQ HPF 300 Гц Q 1.0 + LPF 6 кГц Q 1.0 → JS: Waveshaping Distortion (крутить shape до треска середины).
3. Фейдер трека 2: **−12 дБ**, по вкусу до −8. Саб остаётся чистым на треке 1.

## Шаг 6. REAPER: мастер

На мастер-трек, строго по порядку:
1. **ReaEQ**: HPF 30 Гц Q 2.0 · 220 Гц −2.5 дБ Q 1.0 · 3.2 кГц +2.5 дБ Q 0.8 · полка 9 кГц +1.5 дБ.
2. **ReaXcomp** 4 полосы: 0–120 Гц 4:1 · 120–800 Гц 2:1 · 800 Гц–5 кГц 2.5:1 · 5 кГц+ 2:1 (значения атак/релизов — в скилле, `song/PLAN.md`).
3. **ReaLimit**: ceiling −1.0 dB.
4. Render: WAV 44.1 кГц / 24 бит, *Normalize to LUFS-I −9.5*, *Brickwall True Peak −1.0*.
5. Скинуть рендер мне — проверю LUFS, пик, паузы.

## Шаг 7. Версии

1. **Slowed** (главная для эдитов): свойства итема → Playback rate **0.8**, **Preserve pitch OFF** →
   116 BPM, как test.mp3. ReaVerbate decay 1.2 с, тихо. Отдельный рендер.
2. **Super Slowed**: rate **0.7** (101.5 BPM).
3. **TikTok-луп**: 8 тактов от доли 1 дропа 2 (в оригинале 0:16.552–0:29.793; в slowed 0:20.690–0:37.241).
4. Не выкладывать всё разом: 2–3 версии с интервалом 2–3 недели.
5. При дистрибуции честно отметить AI-генерацию; актуальные правила — у дистрибьютора.
