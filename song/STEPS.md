# Пошагово: от Suno до релиза

Названия полей в Suno меняются. Если какого-то нет — скрин формы, разберёмся по нему.

## Шаг 0. Подготовка

1. Открыть **suno.com**, войти в аккаунт (Pro/Premier).
2. Слева в меню нажать **Create**.
3. Вверху формы переключатель режима: выбрать **Custom** (не Simple).
4. Рядом с кнопкой Create (или вверху формы) выпадающий список модели: выбрать **v6**. Не v6-wild, не v6-mini.
5. Открыть `song/SESSION.md` → таблица «Дубли Suno»: каждую генерацию записываем строкой.

Если какого-то поля нет или оно называется иначе — скрин формы мне, разберёмся по нему, не угадывай.

## Шаг 1. Поиск лупа — инструментал, v6

Цель: найти 1–2 дубля с цепким мотивом и ровной сеткой. Голоса пока нет.

**Форма:**

| Поле / кнопка | Что поставить |
|---|---|
| Режим | Custom |
| Модель | v6 |
| Тумблер **Instrumental** | **ON** (поле Lyrics станет неактивным — так и надо) |
| **Style of Music** | один из трёх промптов ниже, целиком, ничего не дописывать |
| **Title** | `loop A1`, `loop A2`… — чтобы различать в библиотеке |

Раскрыть **Advanced Options** (стрелка/шестерёнка под Style):

| Ползунок / поле | Значение | Зачем |
|---|---|---|
| **Exclude** | `guitar, rap, orchestral strings` | убрать то, что тянет в рок/рэп/оркестр |
| **Style Influence** | **80** | строго держать жанр и 145 BPM |
| **Weirdness** | **45** | чуть ниже нормы (50): сетка ровнее |
| **Variety** | **0** | иначе Suno перепишет BPM и тональность |
| **Max Mode** | **OFF** | для 45-секундного лупа не нужен |
| **Duration** (если есть) | **~45 с** | хватит на 8 тактов + проверку повтора |
| Audio Influence | не появится (аудио не грузим) | — |

**Промпты Style — по одному на генерацию, по кругу:**
```
melancholic jumpstyle phonk, 145 BPM, E minor, sad piano hook, punchy jumpstyle kick, deep 808
```
```
sad anime phonk, jumpstyle bounce, 145 BPM, E minor, bell lead, choir pad, heavy 808
```
```
slowed sad jumpstyle, 145 BPM, E minor, 4-note piano motif, hard kick, deep sub, loop
```

**Порядок:**
1. Заполнить форму с промптом 1 → нажать **Create** → появятся **2 дубля** (10 кредитов).
2. Пока генерится — ничего не менять. Повторить **Create** ещё раз с тем же промптом.
3. Затем по 2 генерации на промпт 2 и промпт 3. Итого **6 генераций = 12 дублей = 60 кредитов**.
4. Если один промпт явно лучше остальных — дальше жать только его.

**Отбраковка каждого дубля** — в плеере Suno, первые 8 секунд, скачивать не надо:

| # | Вопрос | «Нет» → в корзину |
|---|---|---|
| 1 | Удар с первой же миллисекунды? | фейд или тихий хвост в начале |
| 2 | Мотив запомнился за ~1 секунду? | не можешь напеть |
| 3 | В мотиве ≤ 6 нот? | мелодия «бежит» |
| 4 | Второй повтор **такой же**, как первый? | Suno начал развивать тему — самая частая смерть |
| 5 | Удары видно на волне? | сплошная стена |
| 6 | Зацикливается без щелчка? | хромает на стыке |
| 7 | Темп ровный ~30 с? | плывёт |
| 8 | Мелодию слышно с телефона/ноутбука? | один гул саба |
| 9 | Нет поющего голоса? | Suno добавил вокал |

Нормальный выход: **1 годный из 8–16**. Если после 6 генераций ничего — пиши мне, что именно ломалось (номера критериев), поменяю промпт.

**Годный дубль:**
1. На дубле **⋯ (три точки) → Download → MP3**.
2. Загрузить в репо: GitHub → ветка `claude/jolly-wright-erptoy` → папка `song/refs/` → **Add file → Upload files**.
3. Написать мне — проверю темп, дрейф, атаку, повтор.
4. На дубле поставить **лайк/звёздочку**, чтобы не потерять.

## Шаг 2. Полная песня с вокалом — Cover по loop A2, v6

Это полноценная песня (~2 мин), не эдит-луп: длинное интро и куплеты — нормально.

### 2.1 Открыть Cover
1. Слева **Library** → найти **loop A2**.
2. На строке трека **⋯ (три точки)** → **Remix/Edit** (или сразу в меню) → **Cover**.
   Откроется форма Create, где вверху прикреплён loop A2 как аудио.
   Нет пункта Cover → Create → кнопка **Upload / Audio** → загрузить свой `loop A2.wav`.
3. Проверить вверху формы: модель **v6**, режим **Custom**.

### 2.2 Заполнить форму

| Поле | Что сделать |
|---|---|
| Тумблер **Instrumental** | **OFF** — иначе поле Lyrics не используется |
| **Lyrics** | стереть всё, вставить текст из `song/LYRICS.md` целиком, с тегами |
| **Style of Music** | `melancholic jumpstyle phonk, 145 BPM, E minor, airy female vocal, sad piano hook, jumpstyle kick, deep 808` |
| **Title** | `you said forever v1` (дальше v2, v3…) |

### 2.3 Advanced Options

| Ползунок / поле | Значение | Зачем |
|---|---|---|
| **Exclude** | `rap, male vocals, guitar` | без рэпа и мужского голоса |
| **Style Influence** | **60** | жанр держится, но луп не задавлен |
| **Audio Influence** | **60** | мотив и звук A2 сохраняются, но модели есть место на куплеты и бридж |
| **Weirdness** | **30** | меньше сюрпризов в форме |
| **Variety** | **0** | промпт не переписывается |
| **Max Mode** | **ON** | держит голос и стиль на длинном треке |
| **Duration** | **~2:30** | с запасом над формой ~2:06, лишнее режется |

### 2.4 Генерация
1. **Create** → 2 дубля (Max Mode стоит дороже — цену видно на кнопке).
2. Ещё **1 Create** с теми же настройками. Итого 4 дубля.
3. Записать каждый в `song/SESSION.md`.

### 2.5 Проверка каждого дубля (слушать целиком в плеере Suno)
- [ ] это тот же мотив и звук пианино, что в A2;
- [ ] куплеты тише, припев — jumpstyle-дроп с киком и 808;
- [ ] поёт женский воздушный голос, слова наши, без новых куплетов;
- [ ] хук «you said forever / then you were gone» звучит одинаково во всех припевах;
- [ ] бридж реально без барабанов;
- [ ] темп не уплыл к концу;
- [ ] трек кончается, а не обрывается на полуслове.

### 2.6 Если не так — менять ОДНО за раз, сравнивать на одном куске 15–30 с

| Проблема | Действие |
|---|---|
| пианино/мотив не похож на A2 | Audio Influence **+10** (→ 70) |
| весь трек как луп, нет куплетов и бриджа | Audio Influence **−10** (→ 50) |
| не jumpstyle, ушло в поп | Style Influence **+10** (→ 70) |
| голос поёт свои слова / лишние куплеты | проверить, что Instrumental OFF; A/B с голыми тегами без пояснений |
| одна строка спета криво | на дубле **⋯ → Edit → поменять одну строку** (v6) |
| сломалась одна секция | **⋯ → Edit → правка секции текстом**, не помогло → **Replace Section** |
| появился мужской голос/рэп | проверить Exclude, перегенерировать |
| трек короче формы, нет финального припева | **Extend** от середины последнего припева, ровно на границе такта |

### 2.7 Финальный дубль
1. **⋯ → Download → WAV**.
2. Там же стемы: **vocals** отдельно (пригодится в REAPER и для slowed).
3. WAV загрузить в `song/refs/` → мне: проверю темп, форму, точки пауз и пересчитаю карту для REAPER.

## Шаг 3. REAPER: сетка и паузы

1. Перетащить WAV на трек. Выделить от первого кика до кика 5-го такта →
   *Time selection: Set project tempo from time selection (detect number of measures)* → должно быть ~145.
2. Пролистать: сетка совпадает с киками до конца? Нет → дубль под эдит не годится.
3. Включить Snap, **ripple editing OFF**.
4. Паузы (точные времена — я пересчитаю под реальный старт твоего дубля):
   - FREEZE 1: последняя 1/8 такта 2 — выделить по сетке → Delete.
   - FREEZE 2: последняя 1/4 такта 10 → Delete.
5. На каждый край реза фейд **3 мс**.
6. Если нет чистого интро: 2 такта мотива → копия на отдельный трек → ReaEQ HPF 250 Гц Q 2.0 + полка 3 кГц +3 дБ.

## Шаг 4. REAPER: jumpstyle-перегруз (параллельно)

1. Дублировать итем на трек 2.
2. Трек 2: ReaEQ HPF 300 Гц Q 1.0 + LPF 6 кГц Q 1.0 → JS: Waveshaping Distortion (крутить shape до треска середины).
3. Фейдер трека 2: **−12 дБ**, по вкусу до −8. Саб остаётся чистым на треке 1.

## Шаг 5. REAPER: мастер

На мастер-трек, строго по порядку:
1. **ReaEQ**: HPF 30 Гц Q 2.0 · 220 Гц −2.5 дБ Q 1.0 · 3.2 кГц +2.5 дБ Q 0.8 · полка 9 кГц +1.5 дБ.
2. **ReaXcomp** 4 полосы: 0–120 Гц 4:1 · 120–800 Гц 2:1 · 800 Гц–5 кГц 2.5:1 · 5 кГц+ 2:1 (значения атак/релизов — в скилле, `song/PLAN.md`).
3. **ReaLimit**: ceiling −1.0 dB.
4. Render: WAV 44.1 кГц / 24 бит, *Normalize to LUFS-I −9.5*, *Brickwall True Peak −1.0*.
5. Скинуть рендер мне — проверю LUFS, пик, паузы.

## Шаг 6. Версии

1. **Slowed** (главная для эдитов): свойства итема → Playback rate **0.8**, **Preserve pitch OFF** →
   116 BPM, как test.mp3. ReaVerbate decay 1.2 с, тихо. Отдельный рендер.
2. **Super Slowed**: rate **0.7** (101.5 BPM).
3. **TikTok-луп**: 8 тактов от доли 1 дропа 2 (в оригинале 0:16.552–0:29.793; в slowed 0:20.690–0:37.241).
4. Не выкладывать всё разом: 2–3 версии с интервалом 2–3 недели.
5. При дистрибуции честно отметить AI-генерацию; актуальные правила — у дистрибьютора.
