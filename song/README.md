# Песня: montagem / Suno v6

Рабочая папка для трека по флоу `montagem-suno-flow-v2` (Suno v6 → REAPER).

## Структура

- `refs/` — сюда кладём референсы (mp3/wav/flac/m4a). Только для анализа, в Suno чужое аудио не загружаем.
- `refs/analysis/` — отчёты анализатора: `<имя>.json` + `<имя>.png` (волна с тактовой сеткой, первые 4 с, спектрограмма).
- `tools/ref_analyze.py` — анализатор.
- `SESSION.md` — журнал: выводы по референсам, промпты Suno, дубли и вердикты.

## Анализ референса

```sh
pip install librosa soundfile matplotlib   # один раз
python3 song/tools/ref_analyze.py                 # все файлы из song/refs/
python3 song/tools/ref_analyze.py path/to/file.mp3
```

Что меряет и как читать (по критериям отбраковки из флоу):

| Поле | Что значит | Ориентир для montagem |
|---|---|---|
| tempo / drift | BPM по сетке и разброс по треку | 130 или 140, дрейф < 1 BPM |
| key / sub root | тональность и нота основного саба | ля / ля-диез минор, саб A1 = 55 Гц, G#1 = 51.9 Гц |
| first attack / fade-in | когда первый удар, есть ли фейд | атака < 10 мс, фейда нет |
| holes | цифровая тишина ≥ 80 мс | freeze 1/8 или 1/4 доли |
| repeat +2 / +4 bars | похожесть такта на такт через 2 / 4 | ≥ 0.8 = луп один-в-один |
| onsets/bar | плотность событий | для эдита читаемая сетка, не каша |
| bands, phone keeps | баланс полос, сколько энергии выше 400 Гц | лид в 1–3 кГц должен быть слышен |
| LUFS / TP / LRA | громкость | цель мастера −9.5 LUFS-I, −1.0 dBTP, LRA 4–7 |
| sections | границы секций по тактам | дроп 1 на 3-м такте |
